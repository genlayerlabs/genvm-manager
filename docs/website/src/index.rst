GenVM
=====

Reference documentation for the GenVM manager — the host-facing service that runs
`GenLayer <https://docs.genlayer.com/>`_ intelligent contracts on its executor lines.

For tutorials and getting started guides, see the
`main documentation <https://docs.genlayer.com/developers/intelligent-contracts/introduction>`_.

The protocol specification and the Python SDK belong to the executor line that
implements them: start from :external+executor:doc:`the current executor <index>`,
or pick another one in the version catalog.
