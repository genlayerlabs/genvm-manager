# Documentation

| Directory | Holds | For |
|---|---|---|
| [`website/`](website/src/) | the published site: `spec/`, `impl-spec/`, `overview/` | people using GenVM |
| [`contributing/`](contributing/README.md) | tutorial, how-to guides, explanation | people changing this repository |
| [`adr/`](adr/) | dated decision records, an archive | anyone asking what was decided and when |
| [`schemas/`](schemas/) | JSON Schema for the shipped config files and `runner.json` | config authors, referenced from the spec |
| [`internal/`](internal/) | design comparisons written while choosing an approach | us, not published |
